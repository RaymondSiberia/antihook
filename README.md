# АнтиКрючок

Интерактивный тест на устойчивость к интернет-вербовке. Внутри — 12 ситуаций, разбор каждого ответа и итоговый скоринг.

## GitHub Pages

Сайт автоматически собирается и публикуется из ветки `main` с помощью GitHub Actions.

```bash
npm install
npm run build:pages
```

Статическая сборка появляется в `pages-dist`.

## Локальная разработка

```bash
npm run dev
```

Основной интерфейс находится в `app/page.tsx`, стили — в `app/globals.css`.
